# Инструкции для Codex

Этот репозиторий — публичная, обезличенная версия генератора Markdown → DOCX для
диссертации, автореферата и связанных материалов.

Перед планированием следующей реализации прочитать локальный файл
`.agents/ROADMAP.md`, если он существует. Это рабочий блокнот агента, а не
пользовательская документация и не обещание публичного API.

Правила разделения данных:

- в отслеживаемых файлах использовать только демонстрационные ФИО, организации,
  даты, публикации, DOI и научный текст;
- реальный текст диссертации и автореферата, персональные метаданные и реальные
  библиографические записи хранить только в приватном проекте либо локальных
  игнорируемых файлах;
- не переносить рабочие гипотезы и незрелые идеи в README до реализации;
- после реализации функции добавить тесты, затем обновить README отдельным
  описанием фактически работающего поведения;
- сохранять совместимость с Obsidian и текущим синтаксисом стабильных `id`.

Не смешивать изменения генератора с пользовательским содержанием без явного
указания пользователя.
